# Address Book Management System

A simple **C-based Address Book Management System** to manage contact information.

## Features

* Create contacts
* Search contacts
* Edit contacts
* Delete contacts
* List all contacts
* Validate contact details
* Save and load contacts using a CSV file

## Technologies Used

* C Programming
* Structures
* Functions
* Pointers
* File Handling
* String Handling

## How to Run

```bash
gcc *.c
./a.out
```
